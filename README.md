# PasherDokan Website

## Overview - PD

This repository contains the source code for the PasherDokan website, the official web presence for the PasherDokan application. PasherDokan provides digital solutions for local shops, helping them connect with customers, manage inventory, and grow their businesses.

## Description

The PasherDokan website serves as:

- The landing page for potential users and customers
- An informational portal about our services
- A gateway to the PasherDokan application
- A platform to showcase our features and benefits for local shop owners

## Development

This website is built using:

- React with TypeScript
- Vite as the build tool
- TailwindCSS for styling
- Various React libraries for enhanced functionality
